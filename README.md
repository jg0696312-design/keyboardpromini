## Najważniejsze funkcje

- **OmniPoint 3.0 HyperMagnetic** — magnetyczne przełączniki z regulowanym punktem aktywacji.
- **Regulacja 0,1–4,0 mm** — dopasuj aktywację klawiszy do własnych preferencji.
- **Rapid Trigger** — szybkie resetowanie klawisza po jego zwolnieniu.
- **GG QuickSet** — gotowe profile gier dostępne w oprogramowaniu SteelSeries GG.
- **Format Mini** — kompaktowy układ pozwala zaoszczędzić miejsce na biurku.
- Producent deklaruje żywotność przełączników do **100 milionów naciśnięć**.
